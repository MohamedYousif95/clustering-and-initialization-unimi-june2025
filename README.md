## Overview

From-scratch Python implementation of k-means and k-means++ comparing the impact of initialization on clustering quality and stability across synthetic and real-world datasets.

## Project Structure

```text
├── src/
│   ├── distance.py     # squared Euclidean distance primitives
│   ├── init.py         # random_init and plusplus_init seeding strategies
│   ├── kmeans.py       # KMeans class (Lloyd's algorithm)
│   ├── metrics.py      # inertia and silhouette utilities
│   ├── data.py         # data loading and synthetic generation
│   └── experiments.py  # multi-trial runner
├── notebooks/
│   ├── 01_eda.ipynb                  # EDA on the Credit Card Segmentation Dataset
│   ├── 02_synthetic_experiments.ipynb # controlled Gaussian blob experiments
│   ├── 03_real_world_experiments.ipynb# Credit Card Segmentation Dataset full pipeline
│   └── 04_mnist_extension.ipynb      # high-dimensional MNIST extension
├── report/
│   ├── main.tex        # LaTeX report source
│   ├── main.pdf        # compiled PDF
│   └── figures/        # plots generated by notebooks
├── data/
│   └── cc_general.csv  # Credit Card Segmentation Dataset
├── requirements.txt
└── README.md
```

## Running the Notebooks

Run notebooks in order from the `notebooks/` directory or from the project root via JupyterLab:

```bash
jupyter lab
```

> **Note:** `cc_general.csv` is included in the `data/` directory. MNIST (~11 MB) is downloaded automatically from OpenML the first time notebook 04 runs and cached by scikit-learn.

Figures are saved automatically to `report/figures/`.

## Datasets

| Dataset | Source | n | Features | Used in |
| --- | --- | --- | --- | --- |
| Synthetic Gaussian blobs | `src/data.make_blobs` | 2 000 | 2-20 | `02_synthetic_experiments` |
| Credit Card Segmentation Dataset | [Kaggle](https://www.kaggle.com/datasets/arjunbhasin2013/ccdata) | 8 950 | 17 | `01_eda`, `03_real_world_experiments` |
| MNIST (subset) | `sklearn.datasets.fetch_openml` | 5 000 | 784 → 50 PCA | `04_mnist_extension` |

## Implementation Notes

- `numpy` and `matplotlib` are used for computation and plotting.
- `scikit-learn` is used **only** as a utility: `fetch_openml` for MNIST and `PCA` for dimensionality reduction. The clustering algorithms are implemented from scratch.
- All experiments seed `numpy.random.default_rng` and pass the generator explicitly for full reproducibility.
